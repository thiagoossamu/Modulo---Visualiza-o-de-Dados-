Dashboard Interativo de E-Commerce

Aplicação web interativa construída com **Dash** e **Plotly** para análise estatística de dados de e-commerce, migrada de visualizações estáticas.

---

# Tecnologias Utilizadas
* **Python 3.10+**
* **Dash** (Layouts HTML e Callbacks)
* **Plotly Express** (Gráficos interativos)
* **Pandas** (Manipulação de dados)
* **Statsmodels** (Linhas de tendência/regressão)
